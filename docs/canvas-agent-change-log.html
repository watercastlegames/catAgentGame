FIX ①

이름표가 외곽선에 가리던 문제

“이름 태그랑 객체의 테두리 부분이 겹쳐서 뜬다. 이름이 최상위로 올라오게 해달라.”

z-order
증상 고양이 머리 위 이름표가 다른 오브젝트와 그 외곽선(OutlineEffect)에 파묻혀 읽히지 않음.
원인 renderOrder = 30은 걸려 있었지만 깊이 테스트가 켜져 있었음. 깊이 테스트가 살아 있으면 renderOrder와 무관하게 앞의 오브젝트에 가려짐.
해결 재질에 depthTest: false를 걸고 renderOrder를 240으로 올림. 이 둘은 반드시 함께 있어야 동작.
🔍

이름표 자체의 외곽선은 원래부터 꺼져 있었습니다

코드베이스에는 이미 disableOutline(material) 헬퍼가 있고 이름표 재질에도 적용돼 있었습니다(userData.outlineParameters = { visible: false }). 즉 문제는 이름표에 외곽선이 그려지는 것이 아니라 남의 외곽선이 이름표를 덮는 것이었습니다. 그래서 해결책이 outline 쪽이 아니라 깊이·순서 쪽입니다.

FIX ②

작업 중엔 머리 위가 아니라 모니터 위

“고양이가 작업 사무실에서 일할 때는 머리 위에 뜨는 게 사라지고, 책상 모니터 위쪽에서 뜨도록.”

anchor
🎯

왜 이게 맞는 변경인가

꾹꾹이 자세일 때 고양이는 책상에 바짝 붙어 머리가 낮아집니다. 그 상태에서 머리 위에 뜨는 표시는 책상·모니터 지오메트리와 겹쳐 읽기 나빠집니다.

그리고 부수 효과가 하나 더 있습니다 — 마커가 책상 기준으로 붙으면 4마리가 각자 자리에 앉아 있을 때 표시 높이가 일정해집니다. 고양이 자세에 따라 높이가 들쭉날쭉하지 않으므로 “누가 막혔는지 한눈에 스캔”이 빨라집니다. 기획서가 킬러 기능으로 잡은 항목에 직접 도움이 됩니다.

좌표는 계산에서 나왔습니다

마커는 고양이 루트의 자식이고, 루트는 좌석 대기 지점에 놓입니다. 워크스테이션은 그 대기 지점보다 항상 뒤(−Z)에 있으므로, z 오프셋은 스테이션 좌표 − 대기 지점 좌표로 바로 나옵니다.

추가한 상수와 헬퍼

// 작업 중일 때 마커가 옮겨갈 자리 — 좌석 대기 지점 기준의 로컬 오프셋.
const MARKER_DESK_LIFT_Y = 0.12;
const SEAT_DESK_MARKER_OFFSETS: Record<SeatId, THREE.Vector3> = {
  "seat-1": new THREE.Vector3(0, MARKER_DESK_LIFT_Y, -1.17),
  "seat-2": new THREE.Vector3(0, MARKER_DESK_LIFT_Y, -0.7),
  "seat-3": new THREE.Vector3(0, MARKER_DESK_LIFT_Y, -1.2),
  "seat-4": new THREE.Vector3(0, MARKER_DESK_LIFT_Y, -1.36),
};
const MARKER_HEAD_OFFSET = new THREE.Vector3(0, 0, 0);
const MARKER_MOVE_EASE = 7.5;

function markerAnchorFor(seatId: SeatId | "queue", working: boolean) {
  // queue 좌석은 워크스테이션이 없으므로 항상 머리 위를 유지한다.
  if (!working || seatId === "queue") return MARKER_HEAD_OFFSET;
  return SEAT_DESK_MARKER_OFFSETS[seatId] ?? MARKER_HEAD_OFFSET;
}

적용 — 보조 고양이와 주인공 양쪽

순간이동하면 어색하므로 기존 카메라와 같은 이징 방식(1 − exp(−delta × ease))으로 부드럽게 옮깁니다. 프레임레이트와 무관하게 같은 속도로 수렴합니다.

entry.root.position.copy(target);

+ // 책상에서 일하는 동안에는 머리 위가 아니라 모니터 위쪽에 뜬다.
+ entry.marker.marker.position.lerp(
+ markerAnchorFor(seat.seatId, seat.status === "working"),
+ 1 - Math.exp(-delta * MARKER_MOVE_EASE),
+ );

⚖️

뒤쪽 고양이의 이름표가 앞쪽 고양이를 덮습니다

depthTest: false는 말 그대로 깊이를 무시합니다. 그래서 이름표가 정말 모든 것 위에 그려지고, 화면 뒤쪽에 있는 고양이의 이름표도 앞쪽 고양이 몸통 위에 올라옵니다. 고양이가 4마리 겹쳐 보이는 각도에서 어색할 수 있습니다.

대안 — 매 프레임 카메라와의 거리를 재서 renderOrder를 다시 매기면(멀수록 낮은 값) 이름표끼리는 올바른 앞뒤 순서가 되면서 다른 오브젝트보다는 계속 위에 남습니다. 비용은 4회 거리 계산 + 정렬이라 무시할 수준입니다.

지금은 요청대로 단순 최상위로 두었습니다. 실제 화면에서 거슬리면 위 방식으로 바꾸면 됩니다.
