02 · Shared image UI system

공통 이미지 UI 규칙

CSS로 패널을 다시 그리지 않습니다. 프레임·탭·카드·버튼·배지의 표면은 PNG이고 코드는 위치, 데이터, 상태 전환과 접근성만 담당합니다.

PNG가 담당

  • 팝업 프레임·제목 리본·큰 닫기 버튼
  • 탭 기본/선택/눌림/잠김 상태
  • 목록 카드·아이템 카드·버튼·상태 배지
  • 욕구 게이지·빈 상태 일러스트·키캡 메뉴

React/CSS가 담당

  • 캔버스 내부 위치와 반응형 크기
  • 텍스트·수치·선택·잠김 데이터
  • 포커스·키보드·터치·aria-label
  • 열기·닫기·눌림·스크롤 동작
