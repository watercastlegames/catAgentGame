작성 2026-08-06 · 대상 catAgentGame · 미해결 2건을 다음 담당자에게 넘김

넘기는 이유 — 두 문제 모두 원인 후보까지는 좁혔으나 확정 검증을 못 했다. 공통 병목은 하나다: 확인 환경에서 고양이를 “근무 중”으로 만들 수 없었다. 업무를 시작하려면 AI 백엔드가 필요한데, 지금 접속 가능한 모든 경로가 막혀 있다.

미해결 ① 4번 자리 고양이가 책상에 안 앉는다 미해결

증상

4번 자리 고양이에게 일을 맡기면 책상(접이식 노트북)에 앉지 않고 멀찍이 떨어진 곳에 앉아 있다.

확인된 동작 원리 (여기까지는 확실함)

고양이는 대기 중일 때 섬을 배회하고, 근무 중일 때만 제 책상으로 간다. 판정은 상태값이다.

// app/agent-world-3d.tsx
const AUTONOMOUS_STATUSES = new Set(["idle", "completed", "failed"]);  // 이 상태 = 배회

const isSecondaryAutonomous = seat.seatId !== "queue" && !seat.blocked
  && AUTONOMOUS_STATUSES.has(seat.status);

if (!isSecondaryAutonomous) {                            // 즉 status === "working"
  const homeTarget = seatWorldPositions[seat.seatId];    // ← 근무 시 걸어가는 좌표
  const arrivedHome = moveSecondaryTowards(entry, homeTarget, navigationObstacles);
  ambientAnimation = arrivedHome
    ? (seat.status === "working" ? "work" : "idle")
    : "walk";
}
  • 2·3·4번 자리(보조 고양이)는 seatWorldPositions[seatId] 로 간다.
  • 1번 자리(주 고양이, characterRoot)만 별도로 codingDeskTarget 을 쓴다.
  • “앉는 의자”라는 별도 앵커는 없다. 좌표에 도착한 뒤 work 애니메이션 (|Caress_sitting)을 재생하는 구조다. 즉 좌표가 곧 앉는 자리다.

손댄 이력 — 세 번 바꿨고 모두 미검증

시점좌표근거결과
원본(2.18, 0, 1.18)—“멀다” 지적
1차(1.79, 0, 1.18)화면(모니터 판)이 모델 중심에서 x −0.447 빠져 있어 거기 맞춤더 멀어 보임
2차(1.76, 0, 1.02)보정값 반영 + 앞뒤 거리를 2·3번(1.17~1.20)에 맞춤여전히 떨어짐
3차(현재)(2.18, 0, 1.02)다른 자리는 전부 책상과 x 가 동일하다는 규칙 발견 → x 복귀미검증
중요 — 1·2차 변경은 “화면 중심에 맞춘다”는 잘못된 전제였다. 다른 자리를 보면 고양이 x = 책상 x 가 일관된 규칙이다. 3차에서 그 규칙으로 되돌렸다.

한쪽만 고치면 어긋난다. 과거에 실제로 그 실수를 했다.

다음 담당자가 할 일

  1. 고양이를 실제로 근무 상태로 만든다(아래 ②가 풀려야 가능). 대기 중 스크린샷으로는 판단 불가 — 배회가 정상 동작이라 “떨어져 있다”가 당연하게 보인다.
  2. 근무 중 화면에서 4번 고양이와 접이식 노트북의 간격을 본다.
  3. 여전히 멀면 z 를 1.02 → 0.85 근처로 줄여 본다. 책상 모델의 다리·상판 깊이가 다른 자리와 달라 같은 거리라도 더 멀어 보일 수 있다.
  4. 고칠 때 두 상수를 함께 바꾼다.

미해결 ② 대화가 항상 같은 멘트만 즉시 나온다 미해결

증상

무엇을 물어도 즉시 같은 문장이 돌아온다.

지금 나오는 문장의 정체

“대화 AI가 아직 연결되지 않았어요. 서버의 대화 워커가 꺼져 있어요.”

이건 내가 넣은 오류 문구다. AI 응답이 아니라 “백엔드가 없다”는 통보이고, 외부 호출 없이 바로 반환되므로 즉시 뜬다. 조개는 환불된다.

그 이전에는 더 나빴다 — 대화 워커가 죽자 중계가 웹검색 워커로 우회해서, 게임이 함께 보내는 성격 문장([Agent Forest cat persona] You are …)이 그대로 검색어가 되어 “agent 뜻” 사전 결과가 매번 돌아왔다. 그 우회는 제거했다.

다음 담당자가 할 일 — 둘 중 하나

A. 실제 앱(chatgpt.site)에 재배포 — 권장.
