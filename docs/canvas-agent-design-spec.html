03 · SEAT MODEL

중앙에 하나, 그 둘레에 셋

워크스테이션 4개가 이미 씬에 있지만 대각선으로 흩어져 있고 중앙이 비어 있습니다. 세션 하나만 도는 평소에 주인공이 화면 구석에 서게 되므로, 중앙을 1번 좌석으로 잡고 나머지 셋을 둘레로 돌립니다.

왜 중앙이어야 하는가 — 카메라가 거길 봅니다

카메라는 OrthographicCamera, 기준 위치 (0, 9.2, 12.9)에서 lookAt(0, 0.2, 0)입니다. 남쪽에서 북쪽을 내려다보는 구도이고, 화면 정중앙이 정확히 월드 원점입니다.

그런데 현재 워크스테이션 넷은 원점을 비워둔 채 대각선으로 퍼져 있습니다. 세션이 하나만 돌면 그 고양이가 어느 자리에 앉느냐에 따라 화면 구석에 서고, 나머지 세 자리는 비어 휑합니다. 기획서가 핵심 산출물로 잡은 히어로 스크린샷이 구조적으로 안 나옵니다.

중앙을 1번으로 두면 ① 첫 화면이 곧 대표 컷이 되고 ② 1마리 → 4마리로 늘어나는 것이 공간이 채워지는 것으로 보이며 ③ 카메라 제약(yaw ±36°, zoom 0.8~1.2) 안에서 구도가 안정적입니다.

중앙에 꾹꾹이가 있어야 하는 이유 — 이게 이 배치의 핵심 제약입니다

“일하는 모습”을 만드는 연출(모니터 코드 스크롤 + 키캡 눌림 + 꾹꾹이 애니메이션)은 LOW_MONITOR 스테이션에만 붙어 있습니다. 다른 셋은 그냥 서 있는 책상입니다.

그래서 그냥 “아무거나 중앙으로” 옮기면, 세션 하나만 도는 첫 사용자가 가장 중요한 장면인 “고양이가 코딩하는 모습”을 못 봅니다. 완료 연출 다음으로 홍보 가치가 큰 장면인데 말입니다.

따라서 중앙으로 옮길 것은 반드시 LOW_MONITOR입니다. 이동 대상이 2개로 끝나는 것도 이 때문입니다 — seat-2·seat-3은 이미 중앙 좌우에 있어 손댈 필요가 없습니다.

비워지는 두 자리 — 장식과 2단계 예약

A빈자리 A — 구 텐트 자리 부근 (-2.0 ~ -3.0, -3.0 ~ -4.5)
성격섬 북서쪽. 야자수 NW(-3.55, -4.85)와 바위 N(-2.7, -5.7) 사이라 이미 자연물이 둘러싼 구역입니다.
제안기능 없는 순수 배경 장식으로 둡니다 — 모닥불, 접이식 의자, 빨래줄, 아이스박스 같은 캠핑 소품 확장. 이미 있는 캠핑 소품 클러스터와 톤이 맞습니다.
주의여기에 클릭 가능한 것을 놓지 마세요. 기획서 헌법상 클릭 대상은 고양이·소품·라디오로 이미 정해져 있고, 배경 장식이 눌리면 오조작이 늘어납니다. 장애물(obstacle)로만 등록합니다.
B빈자리 B — 구 로우 모니터 자리 부근 (1.1 ~ 3.2, 2.6 ~ 4.4)
성격섬 남동쪽. 바로 남쪽에 BEACH_OFFICE_HUT 충돌박스(0.55~4.35 X, 3.72~6.55 Z)가 이미 있어 건물이 서는 자리라는 맥락이 이미 잡혀 있습니다.

// 대상은 command 실행 승인 하나뿐. fileChange/permissions는 절대 자동 승인하지 않는다.

function tryAutoApprove(method, params) {
  if (method !== "item/commandExecution/requestApproval") return false;

  const cmd = (params?.command ?? "").trim();
  if (cmd.length > 200) return false;                    // ③ 길이 상한

  // ② 블랙리스트 — 하나라도 있으면 즉시 탈락 (이중 방어)
  const DANGER = ["&&", "||", ";", "|", ">", ">>", "<", "`", "$(",
    "sudo", "rm", "mv", "del", "curl", "wget", "chmod",
    "git push", "git reset", "Remove-Item"];
  if (DANGER.some((t) => cmd.includes(t))) return false;

  // ① 화이트리스트 — 정확 일치만. 부분 문자열 매칭 절대 금지.
  const SAFE = [/^git (status|diff|log|show|branch --show-current)$/,
    /^(ls|dir|pwd)$/, /^(node|npm) -v$/];
  return SAFE.some((re) => re.test(cmd));
}
