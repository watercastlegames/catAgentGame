화장실 “여러 개” 요구의 정확한 판정

현재 구현은 물리적 화장실 1개 + 단일 occupant + 대기열이다. 여러 고양이가 동시에 필요해도 한 마리만 사용하고 나머지는 기다린다.

통합 기획서 4부 §5의 제목은 “1개 무료, 추가 구매”지만, 같은 문서 §16은 world-object-layout을 변경하지 않고 물리적 신규 배치도 하지 않는다고 확정했으며 실제 구현안은 하나의 화장실 용량을 100/200/300으로 올리는 tier 방식이다. 따라서 다음 두 항목은 별개다.

기본 1개 사용·대기현재 구현됨
용량 3단계 구매100/200/300 tier 구현됨
물리적 여러 개 배치현재 미구현 · 최종 기획과도 충돌

실제로 화장실을 여러 개 월드에 두려면 기획서의 “물리적 신규배치 없음” 결정을 변경한 뒤, 화장실별 occupant/queue/오염도/충돌 AABB/저장 키를 배열 구조로 다시 설계해야 한다.
