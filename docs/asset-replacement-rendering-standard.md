# Agent Forest 교체 에셋 렌더링 표준

이 문서는 새 3D 객체를 생성하거나 기존 객체를 교체할 때 반드시 함께 적용할
시각 품질 기준이다. 모델 생성 완료만으로 작업을 끝내지 않는다.

## 필수 완료 범위

1. 승인된 2D 콘셉트와 동일한 고정 팔레트를 사용한다.
2. 넓은 색면은 원톤에 가깝게 정리하고 JPEG 노이즈, 얼룩, 구운 조명과
   불필요한 표면 무늬를 제거한다.
3. 모델을 용도에 맞는 폴리곤 수로 리메시한다. 작은 소품은 미세 삼각형이
   외곽선과 색면을 깨뜨리지 않는 수준으로 단순화한다.
4. 의미가 다른 부분은 메시 또는 재질을 분리한다. 예를 들어 밥그릇의 몸체와
   사료를 분리하여 등급 색상 변경이 그릇 전체를 물들이지 않게 한다.
5. 최종 사용 재질은 `Unlit`을 기본으로 한다.
   - GLB에는 가능하면 `KHR_materials_unlit`을 기록한다.
   - 런타임에서 불가피하게 변환할 때는 `MeshBasicMaterial`을 사용한다.
   - base-color 텍스처는 sRGB로 읽고 가능한 최대 anisotropy를 적용한다.
   - normal, roughness, metalness, environment reflection으로 색을 다시
     입히지 않는다.
6. 공통 외곽선은 기본적으로 다음 값을 사용한다.
   - 색상: `#735B4F`
   - 두께: `0.0038`
   - 투명도: `0.72`
   객체 크기 때문에 예외가 필요하면 전후 비교 화면에서 승인받는다.
7. 월드의 낮·노을·밤 상태와 정면·측면 카메라에서 확인한다. Unlit 색면은
   유지하되 월드의 안개, 톤 매핑, 공통 외곽선과는 자연스럽게 어울려야 한다.
8. 실제 월드 적용 전후를 같은 카메라와 렌더 스케일로 캡처해 비교한다.
   얼룩, 계단 현상, 외곽선 끊김, 색 번짐이 있으면 완료로 처리하지 않는다.

## 현재 기준 적용 대상

- 빈 고양이 밥그릇
- 사료가 가득 찬 고양이 밥그릇
- 덮개형 고양이 화장실

위 세 객체의 교체 생성 또는 재생성 시에는 `색면 단순화 → 리메시 → 부분별
재질 분리 → Unlit → 공통 외곽선 → 월드 캡처 비교`를 한 묶음으로 수행한다.
같은 유형의 신규 소품에도 이 절차를 기본값으로 확장한다.

## 교체 작업 기록 규칙

교체 또는 재생성 요청을 받을 때마다 작업 대상별로 아래 항목을 함께 기록하고,
하나라도 빠지면 완료로 보고하지 않는다.

| 기록 항목 | 필수 내용 |
|---|---|
| 대상 | 월드에서 보이는 객체 이름과 빈/가득 참 등 상태 변형 |
| 기준 이미지 | 승인된 2D 콘셉트 또는 이전 최종본 |
| 모델 처리 | 리메시 여부, 분리한 메시와 재질 목록 |
| 텍스처 처리 | 원톤화, 노이즈 제거, 고정 팔레트 적용 여부 |
| 최종 재질 | `KHR_materials_unlit` 또는 런타임 `MeshBasicMaterial` 적용 여부 |
| 외곽선 | 공통 색상·두께·투명도 적용 여부와 승인된 예외 |
| 검증 | 낮·노을·밤 및 정면·측면 비교 결과 |

현재 반영 기록:

- 빈/가득 찬 밥그릇: 런타임 `MeshBasicMaterial` 기반 Unlit 변환 적용.
- 덮개형 화장실: 절차형 재질을 Unlit 재질로 통일.
- 향후 교체 에셋: 이 문서를 먼저 확인하고 위 표의 항목을 작업 단위로 유지.
