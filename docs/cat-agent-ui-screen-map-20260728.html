04 · Image-first boundary

이미지로 만들 것과 코드가 맡을 것

“CSS로 만든 느낌”을 없애려면 보이는 면의 책임을 PNG에 주고, 코드는 조립과 동작만 맡아야 합니다.

PNG가 담당하는 보이는 면

  • 팝업 외곽 프레임과 제목 리본
  • 닫기 버튼 기본·호버·눌림 상태
  • 탭 기본·선택·눌림·잠김 상태
  • 목록 카드 기본·선택·잠김 상태
  • 욕구 게이지 트랙·채움·행복 배지
  • 하단 키캡 기본 및 키별 눌림 상태

CSS/React가 담당하는 기능

  • 캔버스 안 좌표와 안전 여백
  • PC·모바일 반응형 크기
  • 클릭 영역과 키보드 포커스
  • 현재 선택·잠김 상태 전환
  • 텍스트와 숫자 데이터 바인딩
  • 열기·닫기·눌림 애니메이션

07 · Visual acceptance

눈으로 확인할 완료 기준

아래 항목을 모두 만족하고 실제 캡처 전·후 비교가 있을 때만 이번 UI 단계를 완료로 판정합니다.

고양이가 걷거나 멈춰도 이름표 아래 배고픔·배설·행복도가 항상 보인다.
팝업 전체가 PC와 모바일 모두 월드 캔버스 경계 안에 있다.
팝업 프레임·닫기·탭·목록·버튼의 보이는 면이 PNG다.
닫기 버튼은 손가락으로 누를 수 있는 크기이며 눌림 이미지가 분리돼 있다.
두 번째 키캡이 체인 아이콘이 아니라 자리/책상 아이콘이다.
탭과 목록이 기본·선택·잠김 상태에서 서로 다른 이미지로 보인다.
팝업 값과 고양이 이름표 값이 같은 프레임에서 일치한다.
1440×900과 390×844 캡처에서 스크롤 없이 전체 캔버스가 보인다.
