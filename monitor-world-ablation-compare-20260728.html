코딩 화면을 완전히 뺀 최종 월드에서 무엇이 달라지는가?

실제 최종 월드의 동일 카메라·동일 590×884 화면을 매번 새로 로드하고, 캐릭터·환경 애니메이션 시간을 0초에 고정한 뒤 기준 상태에서 한 항목만 제거하거나 바꿨습니다. 꾹꾹이 때 표시되는 실시간 코딩 화면과 눌림 키캡 레이어는 모든 캡처에서 강제로 숨겼습니다. 각 카드 왼쪽은 전체 월드, 오른쪽은 같은 모니터 영역을 확대한 화면입니다.

실제 월드 렌더 경로 단일 요인만 변경 동일 모니터 좌표 130×80px 코딩 화면 오버레이 없음 애니메이션 시간 0초 고정 RGB 차이 정량 측정
가장 큰 전역 변화 톤매핑 제거하면 밝아지지만 월드 전체 색조까지 변해 직접 해결책은 아닙니다.
실질 개선 후보 틴트·아웃라인 베젤의 탁함과 가장자리 점 노이즈를 각각 줄입니다.

현재 확인된 진짜 원인

한 가지 후처리만의 문제는 아닙니다.

실시간 코딩 화면이 전혀 없는 상태에서도 원본 Meshy 모니터 화면의 얼룩과 불균일한 색이 그대로 보입니다. 모니터 틴트와 스케치 아웃라인이 이를 추가로 강조하고 있으며, 재질 강제변환과 CSS 비네팅은 현재 모니터 영역에 거의 영향을 주지 않습니다. 따라서 정적 원본을 개선할 때는 모니터 원본 텍스처 정리 + 모니터 틴트 제거 + 모니터 아웃라인 약화 순서가 안전합니다. 톤매핑 전체 제거는 월드 전반의 색을 바꾸므로 국소 해결책에서 제외합니다.

진단용 URL 모드

정상 URL에는 아무 변화가 없습니다. 비교 캡처는 모든 URL에 &monitorCapture=static을 붙이고 ?monitorAblation=baseline, no-tone-mapping, no-tint, no-material-normalization, no-monitor-outline, no-vignette, two-x-render-scale로 생성했습니다. 이 모드에서는 실시간 코딩 화면, 눌림 키캡, 캐릭터·환경 애니메이션이 모두 정지합니다.
